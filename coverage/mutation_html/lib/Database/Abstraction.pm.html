   69: =head1 DESCRIPTION
   70: 
   71: C<Database::Abstraction> is a read-only ORM for Perl that gives a uniform
   72: interface over CSV, PSV, XML, SQLite, DBM::Deep, and BerkeleyDB files - without writing
   73: any SQL.
   74: 
   75: Key features:
   76: 
   77: =over 4
   78: 
   79: =item *
   80: 
   81: B<No SQL required.>  Use plain Perl method calls for simple lookups and
   82: scans; switch storage formats without changing application code.
   83: 
   84: =item *
   85: 
   86: B<Rich query criteria.>  Pass plain values, SQL wildcards, C<undef> (IS NULL),
   87: comparison operators (C<< > >> C<< < >> C<< >= >> C<< <= >> C<!=>), pattern
   88: operators (C<-like>, C<-not_like>), set operators (C<-in>, C<-not_in>,
   89: C<-between>), and logical groupings (C<-or>, C<-and>).
   90: 
   91: =item *
   92: 
   93: B<Automatic joins.>  Add a C<join> parameter to any select method to
   94: combine tables with INNER, LEFT, RIGHT, FULL, or CROSS joins.
   95: 
   96: =item *
   97: 
   98: B<Chained query builder.>  The C<query()> method returns a
   99: L<Database::Abstraction::Query> object for fluent, composable queries:
  100: C<< $db->query->where(...)->order_by(...)->limit(...)->all() >>.
  101: 
  102: =item *
  103: 
  104: B<Schema introspection.>  C<columns()> lists column names; C<schema()>
  105: returns full type/nullability metadata, using native driver introspection
  106: (C<PRAGMA table_info> for SQLite, C<column_info> for others).
  107: 
  108: =item *
  109: 
  110: B<DSN portability.>  Pass a C<dsn> (plus optional C<username>/C<password>)
  111: to connect to any DBI-supported database (SQLite, PostgreSQL, MySQL, ...)
  112: instead of pointing at a local file.
  113: 
  114: =item *
  115: 
  116: B<Performance.>  Small files are slurped into a RAM hash for sub-millisecond
  117: lookups.  All DBI statement handles are cached with C<prepare_cached()>.
  118: A CHI-compatible cache layer is also supported.
  119: 
  120: =back

  411:

  413: 
  414: =item * C<directory>
  415:

  421:

  424: is skipped entirely and the DSN is used directly.  The SQL dialect is
  425: inferred from the DSN prefix (C<sqlite>, C<postgres>, C<mysql>).

  427: =item * C<username>
  428: 
  429: Database username.  Used only with C<dsn>; ignored for file-based backends.
  430: 
  431: =item * C<password>
  432: 
  433: Database password.  Used only with C<dsn>; ignored for file-based backends.
  434: 
  435: =item * C<dbname>
  436: 
  437: Override the filename stem searched in C<directory> (default: the table

  439: 
  440: =item * C<filename>
  441: 
  442: Override the full filename (relative to C<directory>).  Takes precedence

  444: 
  445: =item * C<host>
  446: 
  447: Remote hostname (or C<user@host>) from which to fetch the data file(s) via

  457: 
  458: A URL (C<http://> or C<https://>) pointing to an HTML page that contains one
  459: or more C<< <table> >> elements.  When present, C<directory> is not required.

 1091:

 1099:

 2858: Force SQL mode with C<< max_slurp_size => 0 >> if slurp fails.
 2859:

 2861: 
 2862: B<Unique key assumption in slurp mode.>  Duplicate values in the key
 2863: column silently overwrite earlier rows.  Disable slurp with
 2864: C<< max_slurp_size => 0 >> if duplicates are expected.

 2868: B<BerkeleyDB does not support joins or the chained query builder.>
 2869: 
 2870: =item *
 2871: 
 2872: B<Column names must be valid SQL identifiers> (letters, digits,
 2873: underscores, and a single dot for C<table.column> join notation).
 2874: Other characters will cause a croak.
 2875: 
 2876: =item *
