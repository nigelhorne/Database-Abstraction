   66: =head1 DESCRIPTION
   67: 
   68: C<Database::Abstraction> is a read-only ORM for Perl that gives a uniform
   69: interface over CSV, PSV, XML, SQLite, DBM::Deep, and BerkeleyDB files - without writing
   70: any SQL.
   71: 
   72: Key features:
   73: 
   74: =over 4
   75: 
   76: =item *
   77: 
   78: B<No SQL required.>  Use plain Perl method calls for simple lookups and
   79: scans; switch storage formats without changing application code.
   80: 
   81: =item *
   82: 
   83: B<Rich query criteria.>  Pass plain values, SQL wildcards, C<undef> (IS NULL),
   84: comparison operators (C<< > >> C<< < >> C<< >= >> C<< <= >> C<!=>), pattern
   85: operators (C<-like>, C<-not_like>), set operators (C<-in>, C<-not_in>,
   86: C<-between>), and logical groupings (C<-or>, C<-and>).
   87: 
   88: =item *
   89: 
   90: B<Automatic joins.>  Add a C<join> parameter to any select method to
   91: combine tables with INNER, LEFT, RIGHT, FULL, or CROSS joins.
   92: 
   93: =item *
   94: 
   95: B<Chained query builder.>  The C<query()> method returns a
   96: L<Database::Abstraction::Query> object for fluent, composable queries:
   97: C<< $db->query->where(...)->order_by(...)->limit(...)->all() >>.
   98: 
   99: =item *
  100: 
  101: B<Schema introspection.>  C<columns()> lists column names; C<schema()>
  102: returns full type/nullability metadata, using native driver introspection
  103: (C<PRAGMA table_info> for SQLite, C<column_info> for others).
  104: 
  105: =item *
  106: 
  107: B<DSN portability.>  Pass a C<dsn> (plus optional C<username>/C<password>)
  108: to connect to any DBI-supported database (SQLite, PostgreSQL, MySQL, ...)
  109: instead of pointing at a local file.
  110: 
  111: =item *
  112: 
  113: B<Performance.>  Small files are slurped into a RAM hash for sub-millisecond
  114: lookups.  All DBI statement handles are cached with C<prepare_cached()>.
  115: A CHI-compatible cache layer is also supported.
  116: 
  117: =back

  390: =head2 new
  391: 
  392: Create an object pointing to a read-only database.
  393: 
  394: Accepts arguments as a hash, a hashref, or - as a shortcut - a single bare
  395: string which is taken to be C<directory>.
  396: 
  397: =head3 Connection parameters
  398: 
  399: =over 4
  400: 
  401: =item * C<directory>
  402: 
  403: Directory containing the data files.  The module probes this directory for
  404: files named after the subclass (see L</FILE FORMATS>).  Required unless
  405: C<dsn> is given.
  406: 
  407: =item * C<dsn>
  408: 
  409: A DBI data-source string (e.g. C<dbi:SQLite:dbname=/path/to/db> or
  410: C<dbi:Pg:dbname=mydb;host=db.example.com>).  When present, file detection
  411: is skipped entirely and the DSN is used directly.  The SQL dialect is
  412: inferred from the DSN prefix (C<sqlite>, C<postgres>, C<mysql>).
  413: 
  414: =item * C<username>
  415: 
  416: Database username.  Used only with C<dsn>; ignored for file-based backends.
  417: 
  418: =item * C<password>
  419: 
  420: Database password.  Used only with C<dsn>; ignored for file-based backends.
  421: 
  422: =item * C<dbname>
  423: 
  424: Override the filename stem searched in C<directory> (default: the table
  425: name derived from the class name).
  426: 
  427: =item * C<filename>
  428: 
  429: Override the full filename (relative to C<directory>).  Takes precedence
  430: over C<dbname>.
  431: 
  432: =item * C<host>
  433: 
  434: Remote hostname (or C<user@host>) from which to fetch the data file(s) via
  435: SSH/SCP.  When present, each candidate filename is fetched with
  436: L<File::Slurp::Remote> into a local temporary directory; the existing
  437: extension-based file-type detection then runs against that directory.
  438: C<directory> is treated as the remote path (no local canonicalization is
  439: applied).  Using C<filename> together with C<host> avoids probing multiple
  440: extensions and is therefore more efficient.  L<File::Slurp::Remote> must be
  441: installed; it is loaded lazily (only when C<host> is given).
  442: 
  443: =back
  444: 
  445: =head3 Behaviour parameters
  446: 
  447: =over 4
  448: 
  449: =item * C<no_entry>
  450: 
  451: Set to C<1> when the table has no key column (standard CSVs, for example).
  452: Default is C<0> (keyed on C<entry>).
  453: 
  454: =item * C<id>
  455: 
  456: Name of the key column.  Default is C<entry>.
  457: 
  458: =item * C<sep_char>
  459: 
  460: Field separator for CSV/PSV files.
  461: Default is C<!> - pass C<< sep_char => ',' >>
  462: for standard comma-separated files.
  463: 
  464: =item * C<max_slurp_size>
  465: 
  466: Files smaller than this (in bytes) are loaded entirely into memory for fast
  467: lookups.  Default is 16 KB.  Set to C<0> to force SQL mode for all sizes.
  468: 
  469: =item * C<no_fixate>
  470: 
  471: Set to C<1> to return mutable arrays.  Default is C<0> (arrays are made
  472: read-only via L<Data::Reuse>).
  473: 
  474: =item * C<auto_load>
  475: 
  476: Set to C<0> to disable the AUTOLOAD column shortcut.  Default is C<1>
