   67: =head1 DESCRIPTION
   68: 
   69: C<Database::Abstraction> is a read-only ORM for Perl that gives a uniform
   70: interface over CSV, PSV, XML, SQLite, and BerkeleyDB files - without writing
   71: any SQL.
   72: 
   73: Key features:
   74: 
   75: =over 4
   76: 
   77: =item *
   78: 
   79: B<No SQL required.>  Use plain Perl method calls for simple lookups and
   80: scans; switch storage formats without changing application code.
   81: 
   82: =item *
   83: 
   84: B<Rich query criteria.>  Pass plain values, SQL wildcards, C<undef> (IS NULL),
   85: comparison operators (C<< > >> C<< < >> C<< >= >> C<< <= >> C<!=>), pattern
   86: operators (C<-like>, C<-not_like>), set operators (C<-in>, C<-not_in>,
   87: C<-between>), and logical groupings (C<-or>, C<-and>).
   88: 
   89: =item *
   90: 
   91: B<Automatic joins.>  Add a C<join> parameter to any select method to
   92: combine tables with INNER, LEFT, RIGHT, FULL, or CROSS joins.
   93: 
   94: =item *
   95: 
   96: B<Chained query builder.>  The C<query()> method returns a
   97: L<Database::Abstraction::Query> object for fluent, composable queries:
   98: C<< $db->query->where(...)->order_by(...)->limit(...)->all() >>.
   99: 
  100: =item *
  101: 
  102: B<Schema introspection.>  C<columns()> lists column names; C<schema()>
  103: returns full type/nullability metadata, using native driver introspection
  104: (C<PRAGMA table_info> for SQLite, C<column_info> for others).
  105: 
  106: =item *
  107: 
  108: B<DSN portability.>  Pass a C<dsn> (plus optional C<username>/C<password>)
  109: to connect to any DBI-supported database (SQLite, PostgreSQL, MySQL, ...)
  110: instead of pointing at a local file.
  111: 
  112: =item *
  113: 
  114: B<Performance.>  Small files are slurped into a RAM hash for sub-millisecond
  115: lookups.  All DBI statement handles are cached with C<prepare_cached()>.
  116: A CHI-compatible cache layer is also supported.
  117: 
  118: =back

 2522: =head1 KNOWN LIMITATIONS
 2523: 
 2524: =over 4
 2525: 
 2526: =item *
 2527: 
 2528: B<Read-only.>  No INSERT, UPDATE, or DELETE is provided.  C<execute()>
 2529: runs raw read-only SQL.
 2530: 
 2531: =item *
 2532: 
 2533: B<Default CSV separator is C<!>>, not C<,>, for historical reasons.
 2534: Pass C<< sep_char => ',' >> for standard RFC 4180 files.
 2535: 
 2536: =item *
 2537: 
 2538: B<Primary-key column is named C<entry>>, not C<key>, because C<key>
 2539: is a SQL reserved word.  Override with the C<id> parameter.
 2540: 
 2541: =item *
 2542: 
 2543: B<XML slurp is limited.>  Only simple flat XML structures are supported
 2544: in slurp mode.  Multi-key or deeply nested documents will croak.
 2545: Force SQL mode with C<< max_slurp_size => 0 >> if slurp fails.
 2546: 
 2547: =item *
 2548: 
 2549: B<Unique key assumption in slurp mode.>  Duplicate values in the key
 2550: column silently overwrite earlier rows.  Disable slurp with
 2551: C<< max_slurp_size => 0 >> if duplicates are expected.
 2552: 
 2553: =item *
 2554: 
 2555: B<BerkeleyDB does not support joins or the chained query builder.>
 2556: 
 2557: =item *
 2558: 
 2559: B<Column names must be valid SQL identifiers> (letters, digits,
 2560: underscores, and a single dot for C<table.column> join notation).
 2561: Other characters will cause a croak.
 2562: 
 2563: =item *
 2564: 
 2565: B<count() cache is opportunistic.>  Count results are served from cache
 2566: only when a prior C<selectall_arrayref()> or C<count()> call with the
