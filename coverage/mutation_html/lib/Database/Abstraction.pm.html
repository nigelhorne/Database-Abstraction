   66: =head1 DESCRIPTION
   67: 
   68: C<Database::Abstraction> is a read-only ORM for Perl that gives a uniform
   69: interface over CSV, PSV, XML, SQLite, and BerkeleyDB files - without writing
   70: any SQL.
   71: 
   72: Key features:
   73: 
   74: =over 4
   75: 
   76: =item *
   77: 
   78: B<No SQL required.>  Use plain Perl method calls for simple lookups and
   79: scans; switch storage formats without changing application code.
   80: 
   81: =item *
   82: 
   83: B<Rich query criteria.>  Pass plain values, SQL wildcards, C<undef> (IS NULL),
   84: comparison operators (C<< > >> C<< < >> C<< >= >> C<< <= >> C<!=>), pattern
   85: operators (C<-like>, C<-not_like>), set operators (C<-in>, C<-not_in>,
   86: C<-between>), and logical groupings (C<-or>, C<-and>).
   87: 
   88: =item *
   89: 
   90: B<Automatic joins.>  Add a C<join> parameter to any select method to
   91: combine tables with INNER, LEFT, RIGHT, FULL, or CROSS joins.
   92: 
   93: =item *
   94: 
   95: B<Chained query builder.>  The C<query()> method returns a
   96: L<Database::Abstraction::Query> object for fluent, composable queries:
   97: C<< $db->query->where(...)->order_by(...)->limit(...)->all() >>.
   98: 
   99: =item *
  100: 
  101: B<Schema introspection.>  C<columns()> lists column names; C<schema()>
  102: returns full type/nullability metadata, using native driver introspection
  103: (C<PRAGMA table_info> for SQLite, C<column_info> for others).
  104: 
  105: =item *
  106: 
  107: B<DSN portability.>  Pass a C<dsn> (plus optional C<username>/C<password>)
  108: to connect to any DBI-supported database (SQLite, PostgreSQL, MySQL, ...)
  109: instead of pointing at a local file.
  110: 
  111: =item *
  112: 
  113: B<Performance.>  Small files are slurped into a RAM hash for sub-millisecond
  114: lookups.  All DBI statement handles are cached with C<prepare_cached()>.
  115: A CHI-compatible cache layer is also supported.
  116: 
  117: =back

 2420: =head1 MESSAGES
 2421: 
 2422: The table below lists every error that the module can croak or carp, what
 2423: triggers it, and how to resolve it.
 2424: 
 2425: =over 4
 2426: 
 2427: =item C<< I<Class>: abstract class >>
 2428: 
 2429: Direct instantiation of C<Database::Abstraction> was attempted.
 2430: Create a subclass and instantiate that instead.
 2431: 
 2432: =item C<< I<Class>: where are the files? >>
 2433: 
 2434: Neither C<directory> nor C<dsn> was supplied to C<new()>.
 2435: 
 2436: =item C<< I<Class>: I</path> is not a directory >>
 2437: 
 2438: The C<directory> argument exists on disk but is not a directory.
 2439: 
 2440: =item C<< I<Class>: cannot connect: I<$DBI::errstr> >>
 2441: 
 2442: DBI failed to connect to the given C<dsn>.  Check credentials and host.
 2443: 
 2444: =item C<< Can't find a file called 'I<name>' for the table I<T> in I<dir> >>
 2445: 
 2446: None of the probe extensions (C<.sql>, C<.psv>, C<.csv>, C<.db>, C<.xml>)
 2447: matched in C<directory>.
 2448: 
 2449: =item C<< I<Class>: prepare failed: I<$errstr> >>
 2450: 
 2451: C<prepare_cached()> returned false.  Usually a syntax error in an internally
 2452: built query; file a bug if you see this from a normal API call.
 2453: 
 2454: =item C<< _build_where_conditions: unsafe column name 'I<name>' >>
 2455: 
 2456: A criteria key contained characters outside C<[A-Za-z0-9_.]>.
 2457: This is a SQL-injection guard.  Use only valid SQL identifier characters.
 2458: 
 2459: =item C<< join: missing "table" >> / C<< join: missing "on" condition >>
 2460: 
 2461: A join spec hashref is incomplete.  Both C<table> and C<on> are required.
 2462: 
 2463: =item C<< Invalid JOIN type: I<TYPE> >>
 2464: 
 2465: C<type> in a join spec was not one of C<INNER LEFT RIGHT FULL CROSS>.
 2466: 
 2467: =item C<< I<Class>: Unknown column I<col> >> / C<< I<Class>: AUTOLOAD disabled >>
 2468: 
 2469: An AUTOLOAD call was made for a column that does not exist, or AUTOLOAD
 2470: was disabled with C<< auto_load => 0 >>.
 2471: 
 2472: =item C<< Usage: set_logger(logger => $logger) >>
 2473: 
 2474: C<set_logger()> was called without a C<logger> argument.
 2475: 
 2476: =item C<< Usage: execute(query => $query) >>
 2477: 
 2478: C<execute()> was called without a C<query> argument.
 2479: 
 2480: =item C<< XML slurp: I<...> is not yet supported >>
 2481: 
 2482: The XML file structure is too complex for slurp mode.
 2483: Use C<< max_slurp_size => 0 >> to force the DBI/XMLSimple SQL path.
 2484: 
 2485: =item C<< I<Class>: I<method> is meaningless on a NoSQL database >>
 2486: 
 2487: A relational method (C<selectall_arrayref>, C<count>, C<execute>, etc.)
 2488: was called on a BerkeleyDB backend, which only supports key-value lookup
 2489: via C<fetchrow_hashref>.
 2490: 
 2491: =back

 2493: =head1 KNOWN LIMITATIONS
 2494: 
 2495: =over 4
 2496: 
 2497: =item *
 2498: 
 2499: B<Read-only.>  No INSERT, UPDATE, or DELETE is provided.  C<execute()>
 2500: runs raw read-only SQL.
 2501: 
 2502: =item *
 2503: 
 2504: B<Default CSV separator is C<!>>, not C<,>, for historical reasons.
 2505: Pass C<< sep_char => ',' >> for standard RFC 4180 files.
 2506: 
 2507: =item *
 2508: 
 2509: B<Primary-key column is named C<entry>>, not C<key>, because C<key>
 2510: is a SQL reserved word.  Override with the C<id> parameter.
 2511: 
 2512: =item *
 2513: 
 2514: B<XML slurp is limited.>  Only simple flat XML structures are supported
 2515: in slurp mode.  Multi-key or deeply nested documents will croak.
 2516: Force SQL mode with C<< max_slurp_size => 0 >> if slurp fails.
 2517: 
 2518: =item *
 2519: 
 2520: B<Unique key assumption in slurp mode.>  Duplicate values in the key
 2521: column silently overwrite earlier rows.  Disable slurp with
 2522: C<< max_slurp_size => 0 >> if duplicates are expected.
 2523: 
 2524: =item *
 2525: 
 2526: B<BerkeleyDB does not support joins or the chained query builder.>
 2527: 
 2528: =item *
 2529: 
 2530: B<Column names must be valid SQL identifiers> (letters, digits,
 2531: underscores, and a single dot for C<table.column> join notation).
 2532: Other characters will cause a croak.
 2533: 
 2534: =item *
 2535: 
 2536: B<count() cache is opportunistic.>  Count results are served from cache
 2537: only when a prior C<selectall_arrayref()> or C<count()> call with the
 2538: same criteria has already populated it.
 2539: 
 2540: =back
