   69: =head1 DESCRIPTION
   70: 
   71: C<Database::Abstraction> is a read-only ORM for Perl that gives a uniform
   72: interface over CSV, PSV, XML, SQLite, DBM::Deep, and BerkeleyDB files - without writing
   73: any SQL.
   74: 
   75: Key features:
   76: 
   77: =over 4
   78: 
   79: =item *
   80: 
   81: B<No SQL required.>  Use plain Perl method calls for simple lookups and
   82: scans; switch storage formats without changing application code.
   83: 
   84: =item *
   85: 
   86: B<Rich query criteria.>  Pass plain values, SQL wildcards, C<undef> (IS NULL),
   87: comparison operators (C<< > >> C<< < >> C<< >= >> C<< <= >> C<!=>), pattern
   88: operators (C<-like>, C<-not_like>), set operators (C<-in>, C<-not_in>,
   89: C<-between>), and logical groupings (C<-or>, C<-and>).
   90: 
   91: =item *
   92: 
   93: B<Automatic joins.>  Add a C<join> parameter to any select method to
   94: combine tables with INNER, LEFT, RIGHT, FULL, or CROSS joins.
   95: 
   96: =item *
   97: 
   98: B<Chained query builder.>  The C<query()> method returns a
   99: L<Database::Abstraction::Query> object for fluent, composable queries:
  100: C<< $db->query->where(...)->order_by(...)->limit(...)->all() >>.
  101: 
  102: =item *
  103: 
  104: B<Schema introspection.>  C<columns()> lists column names; C<schema()>
  105: returns full type/nullability metadata, using native driver introspection
  106: (C<PRAGMA table_info> for SQLite, C<column_info> for others).
  107: 
  108: =item *
  109: 
  110: B<DSN portability.>  Pass a C<dsn> (plus optional C<username>/C<password>)
  111: to connect to any DBI-supported database (SQLite, PostgreSQL, MySQL, ...)
  112: instead of pointing at a local file.
  113: 
  114: =item *
  115: 
  116: B<Performance.>  Small files are slurped into a RAM hash for sub-millisecond
  117: lookups.  All DBI statement handles are cached with C<prepare_cached()>.
  118: A CHI-compatible cache layer is also supported.
  119: 
  120: =back

  394: 
  395: Create an object pointing to a read-only database.

  397: Accepts arguments as a hash, a hashref, or - as a shortcut - a single bare

  400: =head3 Connection parameters
  401: 
  402: =over 4
  403: 
  404: =item * C<directory>
  405: 
  406: Directory containing the data files.  The module probes this directory for
  407: files named after the subclass (see L</FILE FORMATS>).  Required unless
  408: C<dsn> is given.
  409: 
  410: =item * C<dsn>
  411: 
  412: A DBI data-source string (e.g. C<dbi:SQLite:dbname=/path/to/db> or
  413: C<dbi:Pg:dbname=mydb;host=db.example.com>).  When present, file detection
  414: is skipped entirely and the DSN is used directly.  The SQL dialect is
  415: inferred from the DSN prefix (C<sqlite>, C<postgres>, C<mysql>).
  416: 
  417: =item * C<username>
  418: 
  419: Database username.  Used only with C<dsn>; ignored for file-based backends.
  420: 
  421: =item * C<password>
  422: 
  423: Database password.  Used only with C<dsn>; ignored for file-based backends.
  424: 
  425: =item * C<dbname>
  426: 
  427: Override the filename stem searched in C<directory> (default: the table
  428: name derived from the class name).
  429: 
  430: =item * C<filename>
  431: 
  432: Override the full filename (relative to C<directory>).  Takes precedence
  433: over C<dbname>.
  434: 
  435: =item * C<host>
  436: 
  437: Remote hostname (or C<user@host>) from which to fetch the data file(s) via
  438: SSH/SCP.  When present, each candidate filename is fetched with
  439: L<File::Slurp::Remote> into a local temporary directory; the existing
  440: extension-based file-type detection then runs against that directory.
  441: C<directory> is treated as the remote path (no local canonicalization is

  443: extensions and is therefore more efficient.  L<File::Slurp::Remote> must be
  444: installed; it is loaded lazily (only when C<host> is given).

 2757: =over 4
 2758: 
 2759: =item *

 2761: B<Read-only.>  No INSERT, UPDATE, or DELETE is provided.  C<execute()>
 2762: runs raw read-only SQL.
 2763:

 2781: 
 2782: B<Unique key assumption in slurp mode.>  Duplicate values in the key
